# Kimi Handoff - Theophysics Glyph Pack Polish

## Goal

Polish the first-pass deterministic Theophysics glyph pack without changing the semantic vocabulary or the locked Atlas design language.

## Existing Package

```text
theophysics_glyphs/
  png/          # 24 first-pass PNG glyphs
  svg/          # SVG wrappers for the same visuals
  reference/
    theophysics-glyph-reference-sheet.png
    unicode-fallbacks.md
    kimi_handoff_prompt.md
```

## Do Not Change

- The 24 concept names.
- The file names.
- The rule that ember red appears only for broken invariance.
- The rule that green is reserved for grace-flow / Holy Spirit movement.
- The rule that broken forms are the light form with one invariant broken.
- The rule that Law 9-like breakage should feel like shards, not a clean mirror.
- The rule that coherence is braid/convergence, not a generic star.

## Polish Goals

1. Make every icon legible at 32px, 64px, 128px, and 512px.
2. Make line weights consistent across the whole set.
3. Keep the icons symbolic and instrument-panel-like, not cartoon emoji.
4. Increase contrast for pale light icons while preserving ice-white cores.
5. Make the reference sheet feel like a locked Theophysics artifact:
   - black top bar
   - black bottom bar
   - paper field
   - calm serif typography
   - no decorative clutter
6. Keep the Unicode fallback row.
7. Export final:
   - one SVG per glyph
   - one transparent PNG per glyph
   - one reference sheet PNG
   - one PDF reference sheet if convenient

## Icons To Review Closely

- `definition`: currently too faint.
- `mercy`: needs to read more clearly as lawful repair.
- `coherence`: braid is conceptually right but too tiny/pale.
- `decoherence`: good direction, but needs stronger fray/readability.
- `source-term`: good semantic direction; make the frame boundary clearer.
