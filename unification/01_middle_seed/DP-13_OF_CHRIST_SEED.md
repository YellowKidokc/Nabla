# DP-13 — "OF CHRIST" (definition pill seed, with the three-state structure)
**POF 2828 | 2026-07-30 | Fable | Stage: 01_middle_seed → 02_claim_atoms**
**Label: [T] identification riding [D] structure. A pill defines; it does not claim.**

## PLAIN
Something is "of Christ" when it is lined up with the given reference and turning
further toward it. Things with no will — rocks, rivers, animals — are neither of
nor against; they run the laws they were given and can't do otherwise. Only a
will can be against. And a will set against the reference stays against it even
while producing good-looking output.

## TECHNICAL — the three states, formalized on existing canon
Let W = will coupling, Λ_ref = given reference capacities, s = terminal sign
(canon: s ∈ {−1, 0, +1}; the binary lives ONLY here, never in the laws).

STATE N (neutral / instrumental): W = 0.
  Rocks, rivers, animals (W ≈ 0 at the morally relevant coupling). They satisfy
  the laws structurally — often at high Xᵢ — but "of/against" is UNDEFINED for
  them: no will, no orientation, no sign. Not wrong. Not right. Participating.
  (This is why creation can declare glory without being saved or lost.)

STATE A (of Christ): W ≠ 0 ∧ orientation aligned with Λ_ref ∧ Ẋ-component
  toward fuller alignment (the "structured toward" clause — state AND direction).
  A broken thing turning qualifies. χ may be low; the orientation is what counts.

STATE R (against): W ≠ 0 ∧ willful orientation against the reference.
  CRITICAL RIGOR CLAUSE — good output does not flip the sign: high Xᵢ on some
  axes with orientation set against Λ_ref remains State R. Basis: (1) the veto —
  no compensation across axes; (2) orientation is measured against the
  reference, never against internal order (the coherent-lie rail: Jacobson's
  fraud was superbly coherent; a tumor is highly organized — internal coherence
  is NEVER the test); (3) the latch/walk split — works are walk-sector values,
  the sign is not a walk-sector quantity.

## IS-NOT
- Not "anything coherent is of Christ" (admits the coherent lie — REJECTED form).
- Not a moral score: State A at low χ and State R at high visible output are
  both possible and both expected.
- Not a claim that animals/rocks lack value — State N is participation, not
  deficiency.
- Not decidable by observers from output alone (orientation is not fully
  observable; the equation records, it does not sanctify — canon).

## SEED CLAIM (to mint as UC-11, status conditional, when gate clears)
"Of Christ" is definable as reference-aligned, reference-directed coherence for
willed systems, with a principled neutral class for unwilled systems, and with
output-independence of the sign for willed systems. [T/D]
KILLS: (1) a willed system shown to change sign by output alone; (2) the neutral
class shown incoherent (an unwilled system requiring a sign); (3) reference-free
coherence shown sufficient (the coherent lie succeeding as "of Christ" under
the definition as written).

*Scripture anchors for the [T] layer (cite, don't launder): Col 1:17 (wrapper);

not do many mighty works" — the output-independence clause in canon text).*
