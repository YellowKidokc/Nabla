# UNIFICATION DEFINITION PILLS — SEED v0.1
**POF 2828 | 2026-07-30 | Fable | Stage: 01_middle_seed → target 02_claim_atoms as translation/definition nodes**
**Format per pill: PLAIN (Monday morning) → TECHNICAL → IS-NOT (the misuse it blocks) → status**
**Rule: pills define; they never claim. No pill carries a claimID.**

## DP-01 unification (classical)
PLAIN: Showing that things everyone thought were separate are actually one thing — and proving it by what breaks, what's predicted, and what gets simpler.
TECHNICAL: Satisfaction of five criteria: one formal structure; native results preserved as limiting cases; net parameter reduction; novel prediction; a negative control that could have failed.
IS-NOT: A shared vocabulary, a mood, or a metaphor that fits everything. Fitting everything with nothing at stake is the failure mode, not the goal.
STATUS: active

## DP-02 constraint-class vs reduction-class
PLAIN: Two ways to unify. Reduction says "these two forces are secretly one force." Constraint says "one rule governs every domain without replacing any domain's own laws" — like the Second Law or Noether's theorem.
TECHNICAL: Reduction-class: common dynamical origin (electroweak). Constraint-class: domain-general invariance/bound structure over native dynamics. This project claims constraint-class ONLY.
IS-NOT: A retreat. The Second Law replaced nothing and governs everything; nobody calls it decoration.
STATUS: active

## DP-03 socket
PLAIN: A slot in the framework where one domain's own mathematics plugs in — the domain keeps its own equations; the slot only says what shape must fit.
TECHNICAL: A graded attachment point mapping a native quantity/equation into a coordinate role, with the grade set by what the native mathematics actually supports (trial-stack verdicts).
IS-NOT: A replacement for the native equation, ever (blocked overclaims 14, 20).
STATUS: active

## DP-04 wrapper
PLAIN: The thing that holds the nine together from outside — not a tenth ingredient.
TECHNICAL: FORM-C: χ(X) = C_W[∏₁⁹ Xᵢ]; C_W outside the product, identity in the tested case, C_W(0)=0 required if veto is retained.
IS-NOT: A factor. Any ten-factor product is the retired C-inside form. (Corrected in bootstrap review; enforce at render.)
STATUS: active

## DP-05 boundary condition
PLAIN: The given circumstances at the edge of a system — what it starts with and what its edges touch — which the system cannot rewrite from inside.
TECHNICAL: Initial/edge data required to close a well-posed problem; distinct from the governing equation; in this project the recurring residence of externality (L in orbits, η in dynamics, ref capacities).
IS-NOT: A fudge term. A problem without stated boundary conditions is unfinished, not flexible.
STATUS: active

## DP-06 bridge grade
PLAIN: How strong a cross-domain connection is, stamped on the connection itself — and whether bad news travels across it.
TECHNICAL: Four grades on edges: structural_identity (propagates falsification), structural_isomorphism (propagates), structural_analogy (does not), metaphorical (does not). Grades live on edges, never on nodes.
IS-NOT: A vibe. An ungraded bridge is an unfinished bridge; a silently upgraded one is a violation.
STATUS: active

## DP-07 coordinate Xᵢ and reference capacity Λᵢ^ref
PLAIN: Each axis is scored as a fraction of its own fullness — you can't score anything without first saying what full looks like.
TECHNICAL: Level 0: Λᵢ = Aᵢlog₂(1+Tᵢ/Dᵢ) [bits/s]. Level 1: Xᵢ = Λᵢ/Λᵢ^ref ∈ [0,1]. The reference is itself a capacity; the equation multiplies fractions, never raw rates.
IS-NOT: Unitless by nature. The units exist at Level 0 and are shed at the boundary — "did you divide by full capacity first?"
STATUS: active

## DP-08 warrant labels (D/C/E/P/H/T/A/O)
PLAIN: Every claim wears a tag saying what KIND of support it has, so a proof, a measurement, an argument, and a confession can never impersonate each other.
TECHNICAL: Derived / Conditional / Empirical / Philosophical / Historical / Theological / Analogy / Open — mandatory on every conclusion; governs what may cite what.
IS-NOT: A confidence score. A [T] at full conviction is still [T]; a shaky [D] is still [D].
STATUS: active

## DP-09 veto property
PLAIN: One dead channel kills the whole score. Nothing on the other eight buys it back.
TECHNICAL: ∃i: Xᵢ=0 ⇒ χ=0; machine-verified through the wrapper given map_zero. Encodes necessity (each axis necessary, none compensatory).
IS-NOT: A penalty someone added. It arrives with multiplication itself.
STATUS: active

## DP-10 openness / external slot (η)
PLAIN: The one place the system is open to something it cannot generate — required, not optional, if stuck states are ever escaped.
TECHNICAL: η(X,t): source term, provably not a function derivable from ∇χ (annealing/local-minimum theorem); bridge identification η = grace is a naming, never a theorem.
IS-NOT: A tuning knob. If η is fitted per-outcome, the pre-registered failure condition fires.
STATUS: active

## DP-11 negative control
PLAIN: A test built to fail — because if everything passes, the test proves nothing.
TECHNICAL: A condition under which the framework's move must NOT work (random-order path claim: FAILED, correctly). Required companion to every law-order or pattern claim.
IS-NOT: Pessimism. It is the difference between structure and numerology.
STATUS: active

## DP-12 governor (meta layer) — DESIGN TERM ONLY
PLAIN: The sky above the claims: rules every question passes through before it touches knowledge — labels enforced, overclaims rejected, grades respected.
TECHNICAL: Proposed node class routing API traversal: resolve governors → admit atoms by status/grade → assemble → stamp labels. NOT YET A NODE TYPE — schema and routing design required first (bootstrap review ruling).
IS-NOT: Implemented. This pill reserves the word; it does not create the object.
STATUS: draft (blocked on schema)
