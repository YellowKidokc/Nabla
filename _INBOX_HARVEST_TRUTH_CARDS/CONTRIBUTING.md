# Contributing

This project is meant to make a speculative cross-domain model easier to test,
criticize, and sharpen. Contributions are welcome when they make the formal
status of a claim clearer.

## Useful contribution types

- Tighten a definition.
- Replace an axiom with a theorem.
- Show that a proposed theorem is false under the current definitions.
- Add a countermodel.
- Move a claim in `PaperClaims.md` to a more accurate status.
- Improve documentation around what Lean can and cannot establish.

## Standards

- Keep empirical, theological, and formal claims clearly separated.
- Prefer small theorems with explicit assumptions.
- Avoid proving a claim by baking the conclusion into the definition unless the
  README or claim matrix says that is exactly what is being demonstrated.
- Run `lake build` before opening a pull request.
