## The Complete Flow (One Diagram)

```

            │  CLAIM ENTERS │
            └──────┬───────┘
                   │
           Q0: POSTURE CHECK
           "Honest inquiry?"
                   │

           Fix domain, scale, regime, ISO
           ⚠ domain confusion · scale mismatch · false ISO
                   │
           Q3: WHAT IS CLAIMED?

           ⚠ vague claim · scope creep · moving target
                   │

           Q5: WHAT MUST ALREADY BE TRUE?
           Dependency chain → axiom floor
           ⚠ hidden assumptions · circular deps · false floor
                   │

           Predictions: confirmed | untested | decisive | failed
           ⚠ no predictions · post-hoc · unfalsifiable
                   │
           Q7: HOW DOES THIS DIE?
           Five universal deaths + domain kills
```

## Truth Score Synthesis

After Q0–Q7, compute the Truth Score from six variables:

```
T = mean(S, E, L, D, P, C)

S = Survivability   ← Q7 (how many kills survived?)
E = Evidence        ← Q4 (E_final from three channels)
L = Logic           ← Q3 precision × Q4 ED
D = Dependencies    ← Q5 (clean chain? hidden assumptions?)
P = Predictions     ← Q6 (confirmed / total)
C = Coherence       ← Q2 (cross-domain consistency)
```

| Score | Confidence Level |
|-------|-----------------|
| 0.85+ | **ESTABLISHED** — multiple independent confirmations |
| 0.70–0.84 | **WELL SUPPORTED** — strong but gaps remain |
| 0.55–0.69 | **TENTATIVE** — promising but needs more evidence |
| 0.40–0.54 | **SPECULATIVE** — interesting but weak foundation |
| < 0.40 | **PROBLEMATIC** — significant issues, may be dead |
