# Migration — Periodic-15 v0.3 Contract Alignment

**Date:** 2026-08-12
**Authority:** Consilience Atlas Canonical Architecture v0.3 (2026-08-11), section 9 (fifteen-marker contract) and section 18 (schema changes required before freeze).
**Status:** Applied. This was a deliberate ruling/patch of the contract drift flagged in the 2026-08-11 session summary, not a silent rename.

## What drifted

The pushed schema (`meta/schemas/atlas_record.schema.json`) and the Atlas rails carried a **pre-freeze** marker contract, while the v0.3 architecture document and the merged Atlas workbench (`templates/atlas-workbench.html`, PR #3) had already frozen the new one. Three naming/semantics layers disagreed:

| Layer | Old (retired) | New (frozen) |
|---|---|---|
| Schema / `periodic15.py` / rails | `marker_N_*`, pre-freeze semantics | `m##_name`, v0.3 semantics |
| Workbench template | — (already new) | `m01_identity` … `m15_alert_state` |

The backend was aligned to the workbench key format (`m##_name`) so the whole stack speaks one contract.

## Other contract changes in the same patch

1. **Bridge objects expanded** (v0.3 §12, §18.6): bridges now carry `source_id`, `target_id`, `source_domain`, `target_domain`, `direction` (`A_to_B` / `B_to_A` are separate claims), a full `manifest` (`preserved` / `lost` / `introduced` / `forbidden`), `assumptions`, `negative_controls`, `ablation_result`, `provenance_distance`, `reference_independence`, `dispute`, `grade`, and a `validation_state` lifecycle (`Candidate → Provisional → Admitted → Suspended / Revoked / Rejected`). The old flat `{bridge_id, target, mapping_type, standing, forbidden}` shape is retired.
2. **Epistemic band added** (Master Template v1.1 alignment): top-level required `epistemic` block — `class` (definition / observation / theorem / interpretation / hypothesis / undeclared), `scope_class` (G1–G4 with label and basis), `derivation_status`, `external_independence`, `proposition` (the one irreducible claim), optional `irreducible`, plus `origin` / `confidence` / `confidence_basis` with confidence mandatory for `ai_inference` (v0.3 §17).
3. **Dynamics-7 typed** (v0.3 §18 + DG7 storage rule): `atom_stack.dynamics.dg7` now stores **eight** probed fields — `coherence`, `degradation`, `measurement`, `threshold`, `transition_asymmetry`, `restoration_self`, `restoration_external`, `counterexample` — each a status-bearing probe object (`answered / unknown / unresolved / refused / not_applicable / not_run`) with optional origin/confidence/source spans. Seven questions displayed, eight fields stored; counterexample provenance belongs to the verification architecture.
4. **Γ and Α interfaces added** (v0.3 §6, §18.7–8): top-level required `reference_interface` (Γ — reference failure ≠ interface failure) and `ascent_interface` (Α — cold reconstruction with method/provenance; ascent may not assume it reaches the descent reference). Both are status-bearing so `not_applicable` / `not_run` are honest values.
5. **`audit.open[]` added** (v0.3 §11, §18.4): the audit block now carries the Open/unresolved class explicitly, mirroring the top-level `unresolved` list.
6. **Computed markers nullable** (v0.3 §18.12): `m12_evidence_grade`, `m13_usage_runs`, `m14_graph_degree` are required keys but must be `null` until the deterministic computation layer fills them. Never hand-entered, never AI-fabricated.

## What consumers must do

- **Gold specimens:** `gold/master-equation/atlas-record-v1.master-equation.trilemma.json` was regenerated via `python -m meta.pipeline` and validates against the patched schema. Any other frozen records must be regenerated or migrated with the table above.
- **Workbench template (`templates/atlas-workbench.html`):** no change required — it already speaks `m##_name`. Records emitted before this patch will render raw keys and miss computed-cell styling; regenerate them.
- **External consumers (AXIOM-REACT, Claude master template v1.1):** the `epistemic.*` data-fields now have a schema home. The Claude template's `data-field="epistemic.*"` bindings map directly onto the new block.
- **`meta/atlas/periodic15.py`:** exposes `MARKERS`, `COMPUTED_MARKERS`, `missing_markers()`, and `uncomputed_markers()` for validators.

## Remaining v0.3 §18 gaps (deliberately NOT in this patch)

1. **Cross-Series objects/output** (§18.1) — needs its own schema; not paper-level.
2. **Registry-backed domain enforcement** (§18.2) — registries exist in `meta/registries/`; schema documents the requirement but validation is not yet wired to the registry files.
3. **Closed-loop warning mechanic** (§18.9) — anchors and Reality Mirror exist; the automatic `CLOSED-SYSTEM COHERENCE WARNING` (high internal coherence + absent external anchor) is not yet computed.
4. **Origin-tagging coverage** (§17) — mandatory-confidence discipline is enforced on the epistemic band and DG7 probe fields; extending `origin` to every AI-inferred field remains open.
5. **Ψ Topology Audit** (v0.3 §15) — diagnostic only; no schema surface yet, per its rule that it never changes standing by itself.
