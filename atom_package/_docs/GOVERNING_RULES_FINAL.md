## THE FOUR ROUTE PROFILES

### Route A: Pastoral / Everyday
```
theological grounding → everyday → article → audience
```
For testimony, encouragement, devotional, ordinary-life teaching.
No hypothesis, falsification, or paper required UNLESS the 
content introduces claims that independently require them.

### Route B: Explanatory Article  
```
canonical references → evidence where needed → everyday → 
article → audience
```
For "here is what we found and why it matters."
Article is the primary artifact. Individual claims within it 
receive linked support nodes without forcing the whole article 
to become a paper.

### Route C: Framework Argument
```
canonical → paradigm → synthesis → hypothesis → evidence → 
falsification → objections → everyday → article → audience → 
fulfilled
```
For general mechanisms, laws, isomorphisms, explanatory frameworks.
Formal paper added when scope, novelty, or audience requires one.

### Route D: Formal Paper
```
canonical → definitions/proof/method → evidence → falsification → 
paper → objections → translation → application → article → 
audience → fulfilled
```
For formal treatments warranting doctoral-level rigor.
Paper is a composite rendering of supported nodes — not the 
source of truth and not the endpoint.

## THE CLAIM-BURDEN TABLE

Each claim receives a claimClass. The class generates minimum 
support requirements — NOT the folder it's in.

| Claim Class | Minimum Required Support |
|-------------|------------------------|
| Pastoral exhortation | Scripture/theological grounding; clearly marked application |
| Textual biblical claim | Exact passage; translation note; textual qualification |
| Theological interpretation | Scripture refs; stated interpretive premises; tradition |
| Historical claim | Primary or credible secondary sources; date/scope qualification |
| Empirical claim | Defined observation; source data; method; uncertainty |
| Statistical claim | Dataset inclusion rule; denominator; reproducible calculation; comparison |
| Mathematical claim | Definitions; derivation or proof; domain and boundary conditions |
| Isomorphism claim | Explicit mapping; invariants; bidirectional test; boundary conditions |
| Causal claim | Competing explanations; identification logic; distinguishing evidence |
| Practical application | Source claims; added premises; boundary conditions; application kill condition |

This is deterministic enough for AI automation:
  classify claim → generate required-node contract → 
  inspect linked support → report missing requirements → 
  preserve the artifact's natural route

## THE DESCENT INVARIANT

Every transformation toward a broader audience tracks whether 
meaning survived the trip:

```yaml
descentInvariant:
  claimMeaningPreserved: true | false | unreviewed
  confidencePreserved: true | false | unreviewed
  boundariesPreserved: true | false | unreviewed
  killConditionPreserved: true | false | not_applicable
  addedPremises: []
  omittedMaterial: []
  applicationLeap: none | disclosed | unsupported
  reviewStatus: unreviewed | machine_checked | human_reviewed
```

A claim is descent-complete ONLY when:
1. At least one path reaches an ordinary-person artifact
2. Every edge on that path has a reviewed Descent Invariant
3. Any added application is a separate node with disclosed premises
4. The reader can trace back to the exact source claim

## THE APPLICATION NODE

Translation and application are SEPARATE operations:

**Translation** = meaning-preserving restatement in simpler language.
"Here is what the equation means in ordinary words."

**Application** = inferential leap to practical advice. Adds premises.
"Here is what this means for your marriage / school / vote."

Application can be WRONG even when the source claim is RIGHT.
Application nodes must declare their added premises so they 
can be challenged independently.

## THE FIVE COORDINATES (per GPT)

Every atom declares five independent dimensions:

1. **What is it?** → nodeType (claim, evidence, bridge, kill, 
   paper, objection, translation, application, article, reach, result)
2. **Epistemic state?** → status (captured, proposed, active, 
   verified, weakened, falsified, deprecated, superseded)
3. **Where does it apply?** → domain(s) + boundary conditions
4. **For whom?** → audienceLevel (specialist, doctoral, informed 
   adult, everyday, child, pastor, parent, policymaker)
5. **How derived?** → edges, provenance, bridge grade, confidence, 
   Descent Invariants

Four views generated from these coordinates:
- Canon view → source claims, equations, proof, provenance
- Workbench view → the 14 folders for human production
- Graph view → dependencies, bridges, challenges, propagation
- Public view → descent renderings and applications

## FALSIFICATION PROPAGATION (scoped)

| Failure Type | Propagation Scope |
|-------------|------------------|
| Root claim false | Global — all dependents falsified |
| Mapping invalid | Bridge peers flagged for review |
| Boundary exceeded | Dependents flagged for review |
| Measurement invalid | Local only |
| Empirical instance failed | Dependents flagged for review |
| Interpretation overreach | Local only |
| Application failure | Application node only |

Only root-level logical contradictions propagate globally.
Most empirical failures flag for review, not auto-falsification.

## THE COMPACT FORM

The fourteen numbered folders are stable sorting addresses and 
production work surfaces, not mandatory sequential steps. An 
artifact enters at its natural level and may move among the 
work surfaces in any order required by the work.

No artifact is required to ascend into a doctoral paper merely 
to have value. Upward artifact development is optional and 
claim-dependent. However, every assertion must satisfy the 
evidential, formal, historical, textual, or theological burden 
created by its own claim class.

Downward public descent remains mandatory. Descent is complete 
only when at least one audience-appropriate path reaches ordinary 
people without changing the claim's meaning, confidence, boundaries, 
provenance, or kill condition. Practical applications are new 
inferential nodes and must disclose their added premises.

**Artifacts enter where they belong.
Claims rise only as far as their burden requires.
Truth descends as far as people require.**
