- UC-01 SOCKET: the nine-coordinate Master Equation functions as a boundary-

  not reduction-class. [P/methodological]
- UC-03 ECONOMY: six per-law agency parameters consolidate to one ruled

- UC-04 NECESSITY: each coordinate is necessary, not compensatory (veto,

  self-closure/boundary problem; the external-slot requirement recurs

- UC-06 REFERENCE: every coordinate is measured against a given full
  capacity; the normative pole resides in Λ_ref. [D structure / T naming]
- UC-07 RECEIPT: DT-004 Hubble gradient — pre-registered, dated,
  structure-correlated. [E-pending]
- UC-08 SUBSTRATE: the cross-field coherence aliases instantiate one
  asymmetric ordering structure (typeclass + instances). [O — program]
- UC-09 SPINE: one narrative structure instantiates across the domains
  (story arm; McMillions-class anchors). [A, teaching path]
- UC-10 SYMMETRY: rivals are evaluated under the identical socket tests
  and grades (fairness trial). [methodological, folder 08]
Every UC atom ships WITH its kill edge(s) on creation — no claim enters
the graph unarmed.

## 4. Layer C — The Meta Layer (S4): nodeType `governor`
The thing above the grouping that API calls route through before nodes.
Governor atoms (small, few, load-bearing):
- G-01 LABEL-GATE: the warrant-label taxonomy; every answer must carry one
- G-02 OVERCLAIM-FILTER: the blocked-overclaims registry as a hard reject list
- G-03 GRADE-RULES: bridge grades + propagation semantics (what falsification travels)
- G-04 TRUST-BOUNDARY: what is trusted for formal work vs not
- G-05 CRITERIA: the classical-unification checklist + evidence addresses
- G-06 CONTROLS: negative-control requirement (random-order etc.)
ROUTING RULE: API call → resolve governors for the domain → THEN traverse
claim graph → answer assembled only from atoms whose status/grade the
governors admit → answer stamped with labels and grades.
Effect: the discipline stops being prompt-dependent. It becomes topology.

## 5. Layer D — Orbit Seeding (what descends from each UC)
Per v12: hypothesis, evidence (trial-stack reports, Lean ledger, DT-004
data trail), falsification (kill registry entries as atoms), objections
(steelmen — rival trial feeds this), paper, then the MANDATORY public run:
everyday, worldcheck, application, audience, verdict, revision-return.
Priority order for seeding: UC-01, UC-05, UC-07 first (the wrapper, the
witnesses, the receipt) — they carry the public story.

6. First public descent: UC-05 (the fifty-problems-one-shape story)
