## Status Ladder

Status| Meaning
---|---
FORMAL_VERIFIED| Checks inside a formal system under stated assumptions.
DERIVED_MODEL| Follows from a stated mathematical model or parent equation, pending domain review.
STRUCTURAL_MAPPED| Consistent operator/signature match, not a proof of external reality by itself.
EMPIRICAL_TEST| Produces or implies externally testable predictions.

OPEN_PROBLEM| Named boundary, not a solved claim.
