## MTL Entries

### Entry 1: Ten-factor product form

- **id:** `MTL-001`
- **exact source line or phrase:** `chi = G * M * E * S * T * K * R * Q * F * C`
- **math layer:** Simple product of ten scalar factors. No integral, no coherence operator, no free will gate, no triple integral over dx dy dt.
- **plain-language layer:** The document presents chi as a straightforward multiplication of ten named quantities.
- **theological / philosophical layer:** The factors correspond to Grace, Moral Alignment, Truth Signal, Entropy/Sin, Judgment/Time, Logos/Knowledge, Redemption/Repair, Quantum/Faith, Strong Force/Love, and Coherence.
- **canonical status:** **old/drift** — This is the legacy form. Current Crown form is `chi(W) = C_W[ triple_integral (G*M*E*S*T*K*R*Q*F) dx dy dt ]`. The document treats `C` as a tenth factor in the product, which violates the current Crown rule that `C` is not a tenth factor but the coherence operator output.
- **topbar pill candidate:** **No** — This form is explicitly deprecated by current Crown. Using it in a topbar pill would propagate drift.

### Entry 2: Zero-collapse property

- **id:** `MTL-002`
- **exact source line or phrase:** `if Q = 0, then chi = 0. If G = 0, then chi = 0`
- **math layer:** Zero factor in product collapses the entire product to zero. This is a standard property of multiplication.
- **plain-language layer:** If any essential channel is completely absent, the whole coherence structure fails.
- **theological / philosophical layer:** No single strong channel can compensate for a dead channel. This enforces structural integrity.
- **canonical status:** **current** — The zero-collapse intuition is preserved in the Crown form (the triple integral still collapses if any factor is zero). However, the mechanism differs: in Crown form, the coherence operator `C_W` gates the integral, so collapse is mediated through the operator.
- **topbar pill candidate:** **Yes, with caveat** — The zero-collapse principle is load-bearing and canon-compatible. A pill like "Zero-collapse coherence: one dead channel collapses the whole" would be accurate if it references the Crown form, not the deprecated product form.

### Entry 4: Chi evaluator channel scoring

- **id:** `MTL-004`
- **exact source line or phrase:** `vPos * (100 - vNeg)` per channel, then product across channels
- **math layer:** Each channel has positive signal `vPos` and negative/corrupting signal `vNeg`. Effective score is product of positive and inverted negative. Then static chi is product of all effective channel scores.
- **plain-language layer:** Each channel is scored by how much good signal it has minus how much corruption. Then all channels are multiplied together.
- **theological / philosophical layer:** A deterministic coherence diagnostic skeleton, not a truth oracle.
- **canonical status:** **old/drift** — This is a simplified evaluator that predates the Crown form. The Crown uses a triple integral over continuous domains, not discrete channel scores. The `vPos * (100 - vNeg)` formula is not in the Crown.
- **topbar pill candidate:** **No** — This evaluator form is not canonical and should not be promoted.

## Canon Drift Warnings

### Warning 1: C as tenth factor (CRITICAL)

The document explicitly writes `chi = G * M * E * S * T * K * R * Q * F * C` and treats `C` as an ordinary factor in the product. The current Crown rule states:

> C is not a tenth factor. C is chi / coherence operator output.

This is a clear drift violation. The document's form is the **old/deprecated** form.

**Severity:** High. This is the central equation of the document and it directly contradicts current Crown.

### Warning 2: Missing free will gate

The document's chi form has no `W` (free will gate) and no `C_W` (coherence operator gated by W). The Crown form is:

```
chi(W) = C_W[ triple_integral (G*M*E*S*T*K*R*Q*F) dx dy dt ]
```

The document's form is a static product without the gating mechanism.

**Severity:** Medium. The free will gate is a key Crown innovation.

### Warning 3: Missing triple integral

The document uses a simple product, not a triple integral over `dx dy dt`. The Crown form integrates over spatial and temporal dimensions.

**Severity:** Medium. The integral structure is important for continuous-domain reasoning.

### Warning 4: Chi evaluator scoring formula

The `vPos * (100 - vNeg)` formula is not in the Crown. It may be a useful implementation detail, but it should not be treated as canonical.

**Severity:** Low. This is a supporting formalization, not a core equation.
