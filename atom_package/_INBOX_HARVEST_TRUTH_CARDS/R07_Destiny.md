**CHARGE:** Universal Salvation claims "everyone will eventually be saved—God's love ensures all reach heaven."

**CROSS-EXAMINATION:**

| Q | A | Trap |
|---|---|------|
| "Does choice matter?" | "Eventually all choose God..." | If all eventually choose God, is choice real? Or are you saying God overrides choice? |
| "What about those who refuse grace?" | "No one ultimately refuses..." | Then free will is an illusion. But love requires freedom. Coerced love isn't love. |
| "Why does Scripture speak of eternal punishment?" | "That's metaphorical..." | Matthew 25:46 uses the same word (αἰώνιος) for eternal life AND eternal punishment. Both literal or both metaphorical? |

**THE CHOICE TRAP:**
```
Universal Salvation: All are eventually saved
But: Salvation requires response (g > 0)
g = 0 blocks grace (R04)
Some maintain g = 0 (free will allows refusal)
∴ Universal salvation only works by overriding will
∴ Overriding will contradicts love
∴ Universal salvation contradicts God's character
```

**VERDICT:** GUILTY of negating genuine free will.

| State | Coherence | Stability |
|-------|-----------|-----------|
| Heaven | C = C_max | Stable (attractor) |
| Hell | C → 0 | Stable (attractor) |
| Intermediate | 0 < C < C_max | UNSTABLE |

```
1. σ ∈ {-1, +1} (binary moral sign)

```

- Endpoints are stable; middle is not

## EQUATIONS / FORMALISM

### Bimodal Theorem
```
THEOREM D8:
Stable(C_eternal) ⟺ C_eternal ∈ {0, C_max}

Proof sketch:
1. σ ∈ {-1, +1} (binary)
2. dC/dt = f(σ, Ĝ) (trajectory determined by σ)
3. σ = +1 ∧ Ĝ active → dC/dt > 0 → C → C_max
4. σ = -1 ∧ ¬Ĝ → dC/dt < 0 → C → 0
5. No intermediate stable point (dC/dt ≠ 0 for 0 < C < C_max)
6. ∴ Only two stable states: {0, C_max} ∎
```

### Trajectory Equations
```
For σ = +1 (redeemed):
dC/dt = k₁(C_max - C) + Ĝ_sanctification > 0
lim[t→∞] C(t) = C_max

For σ = -1 (unredeemed):
dC/dt = -k₂C < 0
lim[t→∞] C(t) = 0
```

### Stability Analysis
```
At C = C_max:
dC/dt = 0 (equilibrium)
d²C/dt² < 0 near C_max (stable)

At C = 0:
dC/dt → 0 (asymptotic equilibrium)
d²C/dt² > 0 near 0 (stable from below)

For 0 < C < C_max:
dC/dt ≠ 0 (not equilibrium)
∴ Unstable (trajectories move away)
```

### Binary σ
```
σ ∈ {-1, +1}
¬∃σ = 0 (no neutral)
σ(ψ_S) = +1 iff redeemed
σ(ψ_S) = -1 iff unredeemed
```
