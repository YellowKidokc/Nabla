## QUESTION TYPES (what kind of answers to generate)

**Type 1 — "Does X hold?"**
- Generate: Yes / No / Meaningless / Illusory (max 4-5 branches)
- Most branches die. Usually one survivor.

**Type 2 — "What IS X?"**
- Generate: Every ontological category (material/mental/informational/relational/mathematical/brute/composite)
- More branches. First major kill zones.

**Type 3 — "What grounds X?"**
- Generate: Nothing (brute) / External (regress risk) / Itself (self-grounding) / Illusory / Necessary
- This is where infinite regress kills branches.

**Type 4 — "What must X be?"**
- NOT branching. DERIVATION.
- Given survivors from prior levels, derive necessary properties.
- Output: list of forced constraints.

## DEATH CONDITIONS (apply to EVERY branch)

1. **Self-Refutation** — Does stating the claim destroy it?
2. **Infinite Regress** — Does the answer push the question back forever?
3. **Empirical Contradiction** — Does it contradict what we observe?
4. **Logical Incoherence** — Does it contradict an established node?
