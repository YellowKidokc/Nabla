## HOW TO EXTRACT CLAIMS

For each chapter, pull every distinct claim. Format:

```
### Claim [chapter]-[number]
**Statement:** one sentence, precise
**Type:** empirical | algebraic | structural | historical | theological
**Depends on:** which earlier claims this requires
**Strength:** strong | moderate | needs-work
```

## HOW TO DOCUMENT EVIDENCE

For each claim:
- Has a citation? Note it.
- Has data? Note the source.
- Is algebraic? Note the derivation.
- Is unsourced assertion? Flag it.

## HOW TO FIND BREAKS

For each claim, what's weak:

```
### Break [chapter]-[number]
**Claim affected:** reference
**Issue:** what's wrong
**Severity:** critical | moderate | cosmetic
**Fix:** what would fix it
```

Be honest. A break found by us is a break fixed.
A break found by a hostile reader is a break exploited.
